Commit `.zuse/settings.toml` when everyone working in a repository should get the same Zuse setup. When you add a repository that has no settings file, Zuse creates a starter `.zuse/settings.toml` with empty scripts and common environment-file includes. User preferences remain in `~/.zuse/settings.json` and can be overridden by applicable repository values.

```toml
schemaVersion = 1
autoCreateWorktree = false

file_include_globs = [
  ".env",
  ".env.local",
  ".env.*.local",
]

[scripts]
setup = "bun install"
run = "bun run dev"
archive = ""
auto_run_after_setup = false

[environment_variables]
NODE_ENV = "development"
```

## Top-level fields

| Field | Purpose |
| --- | --- |
| `schemaVersion` | Settings format; currently `1` |
| `defaultProviderId` | Optional provider default for this repository |
| `defaultModel` | Optional model default |
| `defaultRuntimeMode` | Optional runtime permission default |
| `autoCreateWorktree` | Whether new chats default to isolated worktrees |
| `worktreeBaseDir` | Optional custom directory for worktree creation |
| `file_include_globs` | Local files linked into new worktrees |
| `scripts` | Setup, run, archive, and auto-run behavior |
| `environment_variables` | String values passed to repository scripts |

Use the public schema at `https://zuse.sh/schemas/repository-settings.schema.json` for editor validation.

## Edit settings in the app

Open a project's settings from the gear next to it in the sidebar, or from the project's entry under **Repositories** in **Settings**. The page edits the same file and is organized into:

- **Defaults**: a repository **Default agent** and model, and a **Default permission mode**. Leave the overrides off to inherit your global settings.
- **Project permissions**: **Manage** reviews and revokes saved tool permission decisions for this repository.
- **Worktrees**: **Auto-create a worktree for new chats** sets whether the composer's workspace picker pre-selects a fresh worktree. The list shows this repository's existing worktrees and can remove a checkout; uncommitted changes are saved to its branch first.
- **Scripts**: the setup, run, and archive scripts, and **Auto-run after setup**.
- **Environment variables** and **Worktree file includes**.

Do not commit secrets in `[environment_variables]`. Use ignored local files and [worktree file includes](/projects/file-includes) for machine-specific secrets.
