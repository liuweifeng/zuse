## Projects panel

The left panel groups chats under their project. Select a chat to restore its tabs and environment. At the top, **New chat** (`⌘N`) starts a new task, **New project** opens the **Add project** dialog, and **Plugins** opens connected plugins when you are signed in.

Hover a project to start a chat in it or open its **Repository settings**. A project's menu also opens **Archived chats** and **Usage**, and lets you organize projects into named groups.

Press `⌘K` to search chats and run commands from anywhere, or `Ctrl+Tab` and `Ctrl+Shift+Tab` to move between chats in the sidebar.

## Session tabs

Tabs at the top of a chat represent provider sessions. Use **+** or `⌘T` for a new tab when you want another agent or a clean context inside the same task and checkout, and `⌘1` through `⌘9` to jump between tabs. Closing a tab ends that visible session tab; it does not delete the chat's repository work.

## Main tabs

The main area can show the conversation, an opened file, or the **Review** tab, which lists every change on the branch. Opening a file does not replace the chat: use the tab strip to move back. Press `⌘P` to find and open a file in the current project or worktree.

## Workspace panel

The right panel is a dock you arrange per chat. Use **Add panel** to open **Files**, **Terminal**, **Changes**, **PR**, **Plan**, **Browser**, or **Subagents**, and close panels you do not need. You can open several terminals. File paths and terminal working directories follow the active chat environment, including its worktree.

Toggle the projects panel with `⌘B`, the workspace panel with `⌘⌥B`, and the terminal with `⌘J`. `⌘L` moves focus to the composer.

## Settings

Open settings with **Settings…** in the application menu or `⌘,`. Global sections include **General**, **Providers**, **Default models**, **Plugins**, **Remote access**, **Browser**, **Keyboard shortcuts**, **Experimental**, and **Diagnostics**, plus **Cloud workspaces** where available. Each project also appears under **Repositories** with its repository-specific settings.

See [Keybindings](/reference/keybindings) for every customizable command.
