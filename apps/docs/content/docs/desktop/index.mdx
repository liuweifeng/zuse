The desktop app brings the agent conversation and the active checkout into one workspace. Its layout has three persistent zones:

- the **projects panel** on the left, for projects, chats, and app actions;
- the **main area** for session tabs, the chat, an open file, and the **Review** tab;
- the **workspace panel** on the right, a dock of panels such as **Files**, **Terminal**, **Changes**, **PR**, **Plan**, **Browser**, and **Subagents**.

Panes are resizable and can be hidden with commands or keybindings. The top bar shows the active chat's branch and offers **Open in…**, **Run**, and a primary Git action that follows the branch and pull-request state, from **Commit & push** or **Push**, to **Create PR**, **Mark ready**, and **Merge**.

The desktop app runs on macOS and x64 Linux. Keyboard shortcuts in these docs use macOS keys; on Linux, use `Ctrl` where macOS uses `⌘`.
