A provider is the coding agent behind a chat. Zuse ships eight built-in providers and can run any agent that speaks the Agent Client Protocol (ACP). Every provider gets the same durable timeline, tool and edit rendering, model picker, worktrees, and review flow; models, slash commands, sign-in, and limits stay provider-specific.

| Provider | Runtime | Sign-in |
| --- | --- | --- |
| Claude Code | Local `claude` CLI | `claude /login` or an API key; multiple accounts |
| Codex | Local `codex` CLI (0.128.0 or newer) | `codex login` or an API key; multiple accounts |
| Cursor | Bundled Cursor SDK, no CLI | Cursor API key (required) |
| Grok | Local `grok` CLI (0.2.101 or newer) | Grok CLI sign-in |
| Kiro | Local `kiro-cli` | Kiro CLI sign-in |
| OpenCode | Local `opencode` (1.3.15 or newer) | `opencode auth login` |
| OpenCode 2 | Local `opencode2` | `opencode2 auth login` |
| Pi | Local `pi` | `/login` inside Pi |

Zuse detects each provider and reports installation, sign-in, compatibility, and update state in **Settings → Providers**. It does not bundle a paid provider subscription.

## Gemini

Gemini CLI is no longer a built-in provider. Add it from the ACP catalog instead: open **Settings → Providers**, choose **Add** under **ACP agents**, and search for **Gemini CLI**. Chats you started with the earlier built-in Gemini integration stay readable. See [ACP agents](/providers/acp#gemini-cli).
