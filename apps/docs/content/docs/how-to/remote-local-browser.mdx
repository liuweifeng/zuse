Authorize one browser on the Mac's local network without exposing an unauthenticated server or signing in to hosted access.

## Applicability

Use this guide when the browser can reach the Mac over the current network. Use [hosted remote access](/how-to/remote-hosted-access/) when the browser is away from that network.

## Prerequisites

- Zuse is open on the Mac that owns the environment.
- The target browser is on a network that permits device-to-device traffic.
- You can restart Zuse if local network access is currently off.

## Steps

1. In the desktop app, open **Settings → Remote access**.

2. Under **Connections**, find **Local network**. If it is not already available, choose **Turn on**.

3. Confirm **Restart and turn on**.

   Enabling the listener restarts Zuse and stops running agents. Reopen **Settings → Remote access** after the app returns. **Local network** then shows **Available on this network** with its address.

4. Under **Connect another device**, choose **Create link**. In **Connect through**, choose **Local network**.

   Zuse displays a one-time link and a short pairing code. The link expires after five minutes.

5. Choose **Copy link** and open it in the target browser, or choose **Show QR** and scan the code. If the browser asks for a code, choose **Copy code** or read the **Pairing code**.

6. Let the browser finish authorization and load the environment.

   Do not send the link through an untrusted service or open it in a shared browser. Treat the unredeemed link like a temporary password.

## Verification

Confirm that the browser shows the same projects and chats as the Mac. Then return to **Settings → Remote access** on the Mac and verify the browser appears under **Connected devices**, with its label and last-connected time.

The one-time link may now expire without ending the authorized browser session. The browser's device credential remains valid until you revoke it or disable local access.

## Revoke the browser

1. Open **Settings → Remote access** on the Mac.
2. Find the browser under **Connected devices**.
3. Choose **Revoke**.
4. Reload the browser and confirm it shows **Pair this browser**.

Use **Revoke all** for the grouped **Older device access** credentials created by versions that cannot identify clients individually.

## Troubleshooting and recovery

### The link expired

Choose **New link**, or **Create link** again. Old links are not renewable.

### The browser says the versions do not match

Update the environment, then reload the page. Incompatible clients are blocked instead of connecting with a partial protocol.

### The browser cannot reach Zuse

Confirm the Mac is awake, Zuse is open, and **Local network** shows **Available on this network**. Guest and corporate Wi-Fi often isolate clients; move both devices to a trusted network if necessary.

### Authorization expired after a working session

Revoke any stale entry, create a new link, and authorize the browser again. See [connection recovery](/how-to/remote-recover-connection/) for the error-state decision tree.
