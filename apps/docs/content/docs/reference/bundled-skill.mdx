Zuse ships a first-party skill named `zuse` that teaches supported agents how to help with Zuse. It covers:

- repository settings in `.zuse/settings.toml`, setup/run/archive scripts, and files to include in worktrees;
- public schema URLs for user settings, keybindings, and repository settings;
- connected plugins such as Linear, through the plugin tools and `zuse plugins` commands;
- Zuse orchestration tools for starting and following work in other chats and sessions;
- the `zuse` CLI for chats, sessions, cloud workspaces, and preview URLs.

For providers with native skill discovery currently wired in Zuse, it is installed at:

```text
~/.claude/skills/zuse/SKILL.md
~/.codex/skills/zuse/SKILL.md
```

Zuse writes the file when it loads skills for Claude or Codex. If the file differs from the version bundled with the app, Zuse replaces it, so local edits do not persist. Put your own instructions in a separate skill.

The skill is guidance for the agent, not an additional executable or background service. Its instructions point back to Zuse's public configuration contracts so generated settings remain valid.

Other providers do not receive injected fallback skill text. Their normal project instruction and provider-native extension mechanisms continue to work independently.
